# CINEMA 3D Assets Directory

This folder holds the assets for the 3D cinema auditorium website:

- `videos/`: Place your `.mp4` or `.webm` movie trailers or feature films here. Users can also upload/switch videos dynamically through the interface!
- `textures/`: High-resolution normal maps, roughness maps, or custom carpet/leather textures.
- `images/`: Movie poster thumbnails, brand logos, or UI artwork.

The site is built with built-in procedural 60fps dynamic cinema screen generators for "THE LAST LIGHT", "SINTEL", and "A QUIETER WORLD", and seamlessly plays real video files using Three.js `VideoTexture`.
